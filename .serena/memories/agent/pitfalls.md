# Грабли rental-backend

Каждая из них уже сработала.

⚠️ **`pkill -f` убивает сессию агента.** Шаблон совпадает с оболочкой, из которой агент
работает. Останавливать по PID: `kill $(lsof -ti:3200)`.

⚠️ **`SELECT DISTINCT` без `ORDER BY` не даёт гарантии порядка.** Postgres выбирает между
хеш-агрегацией и сортировкой по статистике, и порядок меняется вместе с планом — сам по
себе, по мере роста данных. Замерено: `boots,helmet,sup,gloves,…` против алфавитного.
Ломает сверку с эталоном, то есть главный способ проверки переезда (19.38).

⚠️ **Контрольный тест может ничего не проверять.** Тест «сломай `ORDER BY` — покраснеет»
на трёхколоночном `DISTINCT` зеленеет и на сломанном коде: планировщик на маленькой
таблице даёт один порядок в обоих планах. Прежде чем считать тест защитой, **сломать код
и убедиться, что он покраснел**.

⚠️ **`@fastify/cookie` с 11.1.1 тянет `cookie@2`, требующий Node 22.** Здесь Node 20.
Версия закреплена точно (`11.1.0`), не `^` и не `~`.

⚠️ **`shared` существует в двух копиях** — здесь и в `../rental/shared/`. Правка идёт в
обе одним коммитом; держит их `src/common/test/common-copy.test.ts`. Расхождение не даёт
ошибки: оно даёт клиента, заведённого дважды из-за формата телефона, и обойдённый лимит
броней.

⚠️ **Пустой `CORS_ORIGINS` означает «тот же origin», а не «всем можно».** Ошибка в эту
сторону открывает публичный API любому сайту.

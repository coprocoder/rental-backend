# Документация бэкенда

Техническое — рядом с кодом. Продуктовое (**зачем** так решили) — в `../rental-docs/`.

⚠️ Разделение не формальное: документ про слои и паттерны устаревает в тот же день, когда
меняется код. Рядом с кодом это видно и правится одним коммитом; за директорию отсюда —
не видно никогда.
